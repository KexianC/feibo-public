# 浙里健教-浙江省健康科普数智创新平台

## 启动方式

直接使用 Chrome、Edge 或其他现代浏览器打开 `index.html`。页面使用相对路径加载全部资源，不需要安装依赖或启动服务。

## 系统模块

- 综合工作台：全省业务态势、专题生命周期和个人待办。
- 健康教育科普语料库：采集任务、智能加工、来源管理和人工复核。
- 健康科普内容智能创作：浙里健教智能创作、原创核验、多级审核和数字医生合成。
- 健康科普多媒体资源：资源上传、智能标引、专题管理和渠道发布。
- 健康科普专家库：专家档案、讲座预约、活动执行和满意度管理。
- “天天”健康教育智能体：问答服务、知识依据、风险处置和反馈工单。
- 健康素养监测分析：数据接入、质量治理、多维分析和策略任务。

## 专家名录

专家库依据[《省卫生健康委办公室等关于公布浙江省健康科普专家库分库成员名单的通知》](https://wsjkw.zj.gov.cn/art/2023/9/15/art_1229560650_2491204.html)（浙卫办〔2023〕13号）建立，收录 24 个健康科普分库、2,351 名成员。系统仅采用通知中公开的姓名、分库角色、所属分库和分库牵头单位，不扩写个人职称、个人任职单位、擅长方向或服务区域。

名录以独立脚本随页面加载，支持在 `file://` 环境下直接进行关键词、分库与角色筛选、分页浏览、成员详情查看和讲座预约流转。

系统位于独立目录中，不修改工作区内其他用户端、管理端、后端或 GEO 子模块的任何文件。

## 校验

在当前目录执行 `node tests/expert-directory-smoke.js`，可校验专家名录总数、筛选、分页、兼任角色合并与预约联动。

## 界面资源

系统功能图标采用 Lucide 图标体系并内嵌于页面，可在离线环境直接显示；授权文本见 `assets/LUCIDE-LICENSE.txt`。

健康素养监测分析页面采用本地 Apache ECharts 与浙江省市级 GeoJSON，展示 11 个设区市真实行政边界、分级着色、监测点动效及点击联动。运行时不访问 CDN；ECharts 授权文本见 `assets/vendor/ECHARTS-LICENSE.txt`。
